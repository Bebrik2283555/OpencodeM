# OpencodeM 0.2.4

- **Alpine в терминале**: chroot-режим получал `-i` без `-c`, отсюда «No command to run». Теперь интерактивный терминал запускает `/bin/sh -i` внутри chroot. Проверено: вкладка `alpine` открывает root-шелл в папке чата.
- **Режимы разрешений** в «Настройки → Разрешения»: `default` (спрашивать) и `turbo` (разрешать без вопросов). Turbo подменяет правила агентов на `allow *` и не вызывает запрос для root/phone.
- **Закрыть движок**: уведомление теперь снимается (`stopForeground` + `cancel`), opencode/Alpine/терминалы останавливаются; в приложении — «Движок остановлен». Следующий запуск снова поднимает foreground.
- Сборка 0.2.4, versionCode 8.

Ограничение turbo: встроенные deny конкретных действий (например `skill browser`) всё ещё могут сработать; turbo снимает запросы, но не отменяет явные запреты движка.
