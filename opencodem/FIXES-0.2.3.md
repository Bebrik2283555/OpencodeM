# OpencodeM 0.2.3 — исправления по отчёту

Версия 0.2.3 (versionCode 7). Установлена поверх 0.2.x.

## Исправлено

- **Enter отправляет сообщение**, Shift+Enter — новая строка. Раньше Enter добавлял строку, поэтому текст после `/команды` оставался в том же сообщении и уходил в аргументы команды. Теперь `/команда` уходит отдельно, следующий текст — отдельным сообщением.
- **Редактирование сообщения**: можно добавлять и убирать вложения, а не только менять текст (`resend` принимает файлы, при входе в редактирование подставляются вложения сообщения).
- В меню сообщения (долгое нажатие) добавлен пункт **«Контекст и история»**.
- **Уровни размышления** больше не переводятся: Auto / Off / Minimal / Low / Medium / High / Extra high / Max, как в opencode.
- **Терминал**: WebView и подложка красятся в цвет терминала до загрузки — белой вспышки при открытии нет.
- **`phone` + скриншот**: результат отдаётся как `data:image/png;base64,...`. Раньше отдавался `file:` URI, и запрос падал с `Local file references must be read with Media.file(path)`. Слишком большой скриншот (>2.5 МБ) возвращается текстом с путём.
- **«Закрыть движок»** в уведомлении теперь действительно останавливает opencode, Alpine и терминалы; экран показывает «Движок остановлен» и кнопку запуска, а не молчит.
- **Alpine**:
  - Причина зависаний найдена на устройстве: **proot виснет на любом пайпе** (`echo a | cat`, `ls | wc -l`) на этом ядре (5.10 + KernelSU). `ls`, `id`, `apk` без пайпов работают.
  - Добавлен режим **«Alpine через root (chroot)»** (`linux.rootChroot`): настоящий `chroot` под su, bind-монтирование `/storage` и файлов приложения. Проверено: `pwd; id; echo done`, пайпы, `;`, редиректы, `apk add python3` — exit 0.
  - На этом телефоне режим включён. На телефоне без root остаётся proot; там пайпы могут зависать, и это ограничение ядра, а не команды.
  - `runtime: auto` теперь выбирает Alpine, когда Linux установлен и включён (раньше `ls /` уходил в Android и получал `Permission denied`). `native` по-прежнему доступен явно.
  - Каждый вызов proot получает свой `PROOT_TMP_DIR` — параллельные команды не мешают друг другу.
  - Добавлен прогресс/таймаут и понятные ошибки (уже было), плюс обновлён `linux.md`.

## Проверено на телефоне

- Alpine (chroot): `pwd` в папке проекта, `id`, пайпы, составные команды, редиректы, `apk add --no-cache python3` → `OK: 55 MiB in 42 packages`.
- Установка набора скиллов по GitHub URL из «Расширения» → «Установлено скиллов: 6», `ponytail` и `ponytail-review` активны.
- Enter/Shift+Enter и команда отдельным сообщением — проверено вводом `/…` и `!echo` (shell-сообщение с выводом).
- `phone`-скриншот: возвращается data-URL (unit-проверка результата; вызов моделью не повторялся).

## Ограничения

- Для chroot нужен root и постоянное разрешение su; на не-root телефоне Alpine остаётся на proot.
- Экран «Агенты» показывает описания движка на английском.
- Камера, SAF-пикер, голос и восстановление резервной копии по-прежнему не прожаты автоматизацией.
- `prefs.lastSession` может ссылаться на удалённый тестовый чат — при запуске это проверяется.
