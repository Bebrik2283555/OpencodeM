# OpencodeM 1.0 — что изменено

Дата: 2026-11-10.

## Безопасность

- Обновление APK проверяет подпись: package name, все подписи архива и историю
  сертификатов. Чужой/подменённый APK удаляется.
- Ссылки `file://` из ответа модели открываются только из папки сессии, workspace
  и `Download`/`Documents`/`DCIM`/`Pictures`.
- Claude Code проверяется по `sha512` из `dist.integrity` npm.
- Команда с `su`/`sudo` теперь запрашивает root-разрешение, даже если `root:false`.

## Движок и фон

- `restart()`/`stopEngine()` отменяют boot; отменённый `Engine.start()` уничтожает
  свой процесс — второй движок не остаётся работать.
- Удаление локальной модели ждёт конца ответа и рестартит движок только если
  модель используется.
- Foreground-сервис на `specialUse` — лимит 6 часов для `dataSync` больше не действует.
- «Закрыть движок» отменяет загрузки моделей.
- Остановка engine/local идёт в IO, без фриза интерфейса.
- `opencode.log` обрезается при старте, ошибки читают только хвост.
- Claude Code: watchdog на `run` (60 с) и `usage` (45 с).
- Alpine `wipe`: проверки `su` только при root-chroot, `grep` с таймаутом.

## Память и производительность

- Текст ответа обновляется раз в ~70 мс, а не на каждый токен.
- Undo: не больше 10 снимков и 2 МБ на сессию, не больше 10 сессий в памяти.
- `fileMtimes` ограничен 2000 записями.
- После `loadSessions()` выбрасываются id удалённых чатов из
  `busy`/`sending`/`lastActivity`/`queue`; формы — из `hiddenForms`/`formAnswers`.
- `opencode.json` в `loadProviders()` читается один раз.
- `allProjects()` больше не делает `stat` на главном потоке.
- Local/Tools больше не опрашивают диск/API бесконечно.

## Чистка

- Фото камеры удаляется из кеша после импорта; raw-скриншот — через `finally`.
- При старте чистятся `camera` и `phone-screens`; `files/media` входит в размер кеша.
- Margy-синхронизация удалена полностью: `Margy.kt`, методы Brain, `prefs.sync`,
  упоминания в README; старые `margy.token` и `sync.json` удаляются при старте.
- Удалены `prefs.dynamic` и неиспользуемые зависимости
  `lifecycle-runtime-compose`, `lifecycle-viewmodel-compose`.
- Удалён мёртвый код: `downloadProgress`, `Json.entries`, `Connection.active`,
  недостижимая ветка `SDK_INT >= 28`, ручной цикл в Drawer.

## Плагин

- `undo` удаляет файлы, созданные `write`.
- `event.model` везде читается через `?.`.
- Кэш моделей чистится по сырому JSON API — `variants`, `images` и `cost` не теряются.

## Интерфейс

- Сессия субагента: шапка с агентом и родительским чатом, кнопка
  «Вернуться в основной чат», вместо ввода — «В сессиях субагентов запрещён ввод».
  «Изменить», «Ответить заново» и «Новый чат» скрыты.
- «Контекст»: входные, выходные, кэш чтения, кэш записи. «Входные» включают кэш
  и совпадают с полосой контекста.
- Крестик у сообщения в очереди возвращает его в поле ввода с вложениями,
  скиллами и агентами.
- `app.md` больше не дублирует `## Commands`: раздел остаётся только в
  `linux.md`/`android.md`.

## Локализация

- Проверены все 537 пар `tr(ru, en)`; у каждой есть русская и английская строка.
- Допереведены режимы агента, эффекты разрешений, режим разрешений, типы
  расширений, «Базовый URL», «Скилл», «Попадания в кэш», «Кэш промпта».
- Переведены пользовательские ошибки Engine, Local, Linux, Resume, Updater,
  Extensions, Backup, Archives, ProcessOutput.
- По-английски осознанно: `URL`, `ID`, `MCP`, `JSON`, названия продуктов,
  примеры команд и сырые сетевые ошибки.

## Тесты

- Kotlin: 22/22 — архивы, формы, resume, active/busy, версии, подписи,
  модели, черновики.
- JS: 18/18 (`node --test test-runtime-plugin.test.mjs`), включая undo нового
  файла и root-запрос для `su`. Фикстура сама ставит `MARGY_PERMISSION_MODE=default`.
- `test-runtime.sh`: 5/5 проверок диспетчера runtime.
- Release-сборка подписана и установлена на телефон (versionCode 31, `1.0`).

## README

- Возвращено упоминание, что OpencodeM — продолжение MargyCode.

## Не проверено

- `specialUse`/`onTimeout` — только Android 14+.
- Ленивое декодирование картинок и сохранение комментариев в `opencode.json`
  отложены до следующего релиза.
