OpencodeM — это нативный клиент для [opencode](https://github.com/anomalyco/opencode) под Android. Приложение не просто обращается к удалённому серверу — оно локально запускает настоящий движок **opencode 2.2.5** (скомпилированный на Bun для Android) и взаимодействует с ним через локальный HTTP/SSE API. Всё, что умеет десктопный opencode, работает прямо на вашем смартфоне.

OpencodeM — продолжение **MargyCode**: тот же движок, раскладка данных и идеи, но новый пакет `com.opencode` и новое имя. Старые чаты и настройки MargyCode совместимы после копирования данных приложения.

> [!NOTE]
> **Архитектура: строго `arm64-v8a`**  
> OpencodeM требует 64-битный ARM-процессор (`arm64-v8a`). 32-битная архитектура (`armeabi-v7a`) **не поддерживается**, так как виртуальная машина JavaScriptCore внутри Bun аппаратно завязана на 64-битные указатели (NaN-boxing).

## ✨ Возможности версии 1.0

- **Полноценный движок Opencode 2.2.5:** автономный агент для разработки со всеми инструментами, доступом к файловой системе, терминалом и субагентами.
- **Поддержка как с Root, так и без Root:**
  - Работает из коробки на обычных устройствах без root через PRoot.
  - Полная поддержка root через **KernelSU**, **APatch** и **Magisk** (с интерактивными диалогами подтверждения прав).
  - Высокопроизводительное выполнение команд в Alpine Linux через настоящий root `chroot` (обходит зависания пайпов в PRoot на ядрах Android 10+).
- **Интеграция с Git / VCS:**
  - Полная поддержка Git через окружение Alpine Linux.
  - Экран «Изменения» с просмотром диффов, откатом коммитов и установкой Git в один тап (`apk add git`).
- **Инспектор контекста:**
  - Шторка Material 3 с отображением расхода токенов, стоимости в USD и метрикой попаданий в кэш промпта (⚡ Prompt Cache Hit Rate).
  - Детализация токенов (системный промпт, рабочая область, история) и история сжатия (compaction).
- **Очередь сообщений (Queue & Steering):**
  - Плавающая панель очереди над полем ввода для добавления инструкций во время работы агента.
  - Возможность направлять (steer) или отменять задачи на лету.
- **Локальные офлайн-модели:**
  - Встроенный сервер `llama.cpp` (с оптимизациями под `armv8.2-a+dotprod+fp16` и `i8mm`).
  - Офлайн-запуск Gemma, Qwen и любых моделей в формате GGUF без подключения к интернету.
- **Интерфейс Material You:**
  - Современный Jetpack Compose UI по гайдлайнам Material 3.
  - Динамические цвета на основе обоев рабочего стола на Android 12+.
  - Переключение языка (Русский / English / Автоматически по системе).
- **Встроенное обновление:**
  - Проверка новых релизов с GitHub прямо в приложении и установка APK в один клик.
- **Расширения и экосистема:**
  - Поддержка протокола Model Context Protocol (MCP) — локальные и удалённые серверы.
  - Кастомные OpenAI-совместимые провайдеры, модели и агенты.

## 🛠️ Сборка из исходников

### Требования
- **JDK 17** (например, Temurin 17)
- **Android SDK** (API 35, Build-tools 35.0.0)
- **NDK 28.2+** и **CMake 3.22.1**
- **Git LFS** (для загрузки скомпилированных нативных библиотек в `jniLibs`)

### Сборка релизного APK
В Windows (PowerShell):
```powershell
cd margycode
.\build.ps1
```

В Linux / macOS:
```bash
cd margycode
./build.sh
```

Подписанный релизный APK сохранится в `out/OpencodeM-1.0.apk` и скопируется в корень проекта.
